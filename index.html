ما هي لغة الضاد؟

    
لغة برمجة عربية تعليمية، تكتب أوامرها بالعربية (مثل «اكتب» و«اذا» و«كرر») فتُترجم فوراً إلى JavaScript وتعمل داخل متصفحك، بلا خادم ولا تثبيت.

  
إلى ماذا تهدف؟
    
    
  • تقريب البرمجة لمن لا يتقن الإنجليزية.
    • 
    
  • تعلّم أساسيات البرمجة بلغتك: المتغيرات والشروط والحلقات والدوال.
    • 
    
  • التمهيد للانتقال السهل إلى JavaScript، فلكل كلمة عربية مقابل معروف في القاموس أدناه.
    • 
    
  • بيئة خفيفة تعمل على الهاتف بلا إنترنت بعد التثبيت.

  
القواعد
    
    
  • الأوامر تُكتب في أسطر، وتنتهي الجملة بـ ; (اختيارية في معظم الحالات).
    • 
    
  • الكتل (الشرط والحلقة والدالة) تُكتب بين { }.
    • 
    
  • النصوص بين " " أو ' '، والتعليقات تبدأ بـ //.
    • 
    
  • الأرقام عربية (٣) أو إنجليزية (3)، ويقبل المترجم الفاصلة العشرية ٫ والفاصلة ، والمنقوطة ؛
    • 
    
  • الكلمات المفتاحية محجوزة، فلا تستخدمها أسماء لمتغيراتك.
    • 
    
  • أسماء المتغيرات والدوال بالعربية أو الإنجليزية، ويقبل المترجم الهمزة وبدونها في «اذا/إذا» و«والا/وإلا».
    • 
    
  • الشروط: و وأو وليس، والمقارنة بـ == != > < >= <=. استخدم == للمقارنة و= للتخصيص فقط.
    • 
    
  • التكرار العددي: كرر العدد مرة { }.
    • 
    
  • الترجمة تستبدل الكلمات خارج النصوص فقط، فما بين علامات الاقتباس يبقى كما كتبته.
    • 
    
  • بما أن اللغة تُترجم إلى JavaScript، فأي كود JavaScript داخل برنامجك يعمل أيضاً.
